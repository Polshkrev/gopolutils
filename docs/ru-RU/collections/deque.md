# Дек
Реализация классической двусторонней очереди на основе двусвязного списка.

## Содержание
1. [Использовать](#Использовать)
2. [Реализовать](#реализовать)

### Использовать
Чтобы перемещать элемента в начало дека предусмотрен метод `Use`. Данный метод принимает индекс элемента, который необходимо переместить. Элемент по указанному индексу удаляется со своей текущей позиции и перемещается в начало дека. Если дек пуст, возвращается ошибка `ValueError`. Если указанный индекс больше или равен размеру дека, возвращается ошибка `IndexError`. Если индекс равен нулю, никаких действий не выполняется.

### Реализовать
Данная структура реализует интерфейс `Collection` посредством встроенной структуры [DoublyLinkedList](/docs/ru-RU/collections/doubly_linked_list.md).
