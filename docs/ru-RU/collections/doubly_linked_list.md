# Двусвязный список
Реализация двусвязного списка.

## Содержание
1. [Добавить](#добавить)
2. [Доступить](#доступить)
3. [Удалить](#удалить)
4. [Реализуемые интерфейсы](#implements)

### Добавить
Чтобы Добавить элементов в список предусмотрено два метода. Первый — это, конечно же, метод `Append`, который добавляет в список один элемент. Также доступен метод `Extend`, который добавляет в список несколько элементов в виде `View`.

### Доступить
Чтобы доступить к элементу списка предусмотрен метод `At`, принимающий заданный индекс. Метод возвращает либо указатель на элемент, расположенный по указанному индексу, и нулевой указатель на исключение, либо нулевой указатель на данные и указатель на исключение.

Чтобы измененить списка предусмотрен метод `Update`. Данный метод принимает индекс элемента, который необходимо изменить, и новое значение, которое следует присвоить элементу по указанному индексу. Метод либо обновляет значение элемента и возвращает нулевой указатель на исключение, либо возвращает указатель на соответствующую ошибку: `ValueError`, если список пуст, или `OutOfRangeError`, если индекс превышает размер списка.

### Удалить
Чтобы удалить элементов из списка предусмотрен метод `Remove`. Данный метод принимает индекс элемента, который необходимо удалить. Если список пуст или указанный индекс превышает размер списка, возвращается ошибка `OutOfRangeError`.

### Реализовать
Данная структура реализует интерфейсы `Collection`, `View` и `Sized`.
